# Changelog

## 0.1.0

- Syntax highlighting for `.ov` files: comments, strings (with format placeholders), based and decimal numbers,
  declarations (`module`, `pipeline`, `bundle`, `fn`, `stage`, `struct`, `enum`, `regmap`, `memmap`, `isa`, ...),
  types, port roles, control keywords, built-in methods (`.wrap()`, `.fire()`, `.zext()`, ...), system tasks,
  preprocessor directives and operators.
- Language configuration: comment toggling, bracket matching and auto-closing, indentation on braces.
